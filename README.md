# Prática PaaS — Cadastro simples

Aplicação de teste em HTML, CSS e JavaScript criada para a atividade de implantação e versionamento.

## Testar a aplicação

[Abrir no StackBlitz](https://stackblitz.com/edit/stackblitz-starters-29vzn1qq?file=index.html)

Preencha nome, e-mail, senha (mínimo de 8 caracteres) e confirmação. O formulário verifica se as senhas coincidem e mostra uma mensagem de confirmação. Esta versão é uma demonstração: os dados não são salvos.

## Arquivo principal

- `index.html`: interface, estilos e validação do formulário.
